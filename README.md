# Aquamarina

Aquamarina 是一款基于 Flutter 的英语学习应用，内置离线英汉双词典，集查词、背单词与 AI 句型练习于一体。

## ✨ 功能特性

### 🔍 离线词典

- 内置 ecdict 与 CC-CEDICT 双词典，支持英汉互查、模糊搜索，无需联网
- 搜索历史记录，方便回溯
- 单词详情页展示完整释义，支持语音朗读

### 📖 背单词

- **词书管理**：本地创建词书，支持手动添加和批量导入单词；也可从在线词书库浏览与导入
- **分阶段学习**：浏览 → 选择题 → 主动回忆，循序渐进
- **间隔重复复习**：基于遗忘曲线的复习调度，支持手动调整复习计划
- **拼写练习**：学习或复习完成后，可进入拼写练习巩固记忆
- **词汇测试**：选择题形式测试已掌握词汇，支持自选词书与自定义数量
- **单词总览**：按状态（等待学习 / 已学习 / 已掌握）查看所有单词，支持批量标记
- **复习计划**：查看未来复习安排，支持手动标记已掌握

### 🤖 AI 句型练习

- **句式集管理**：本地创建与编辑句式集，支持从在线语料库浏览与导入
- **两种练习模式**：入门版（选词块组句）与高阶版（自由输入造句）
- **AI 智能批改**：自动评判句子正确性，给出改进建议
- **错题本**：自动收录答错的句子，支持错题重练
- **不重复练习**：可开启跳过已练习过的句子

### 🎙️ 语音朗读

- 内置 TTS 语音合成，支持系统 TTS 和 Edge TTS 两种引擎
- 可调节语速、音量、音色

### 📊 学习统计与打卡

- 打卡日历与 7 天趋势图
- 连续打卡天数追踪
- 今日学习进度与目标完成提醒
- 学习时长统计（按类型：新词学习 / 复习 / 句型练习 / 词汇测试等）

### 📝 个人词库

- **单词笔记**：为单词记录词根词缀、记忆方法、例句等个人笔记
- **单词收藏**：收藏单词方便集中回顾

### 🎨 主题定制

- 亮色 / 深色 / 跟随系统三种模式
- 10 种预设主题色可选

### 💾 数据管理

- ZIP 格式备份导出与导入，支持选择是否包含 AI API Key
- 清除本地数据

### 🔄 应用更新

- 自动检查 GitHub Release 新版本，支持更新频道切换（latest / beta）

### 🔌 灵活 AI 接入

- 预设配置模板：Aquamarina 官方（免费）、OpenAI、DeepSeek
- 支持自定义 OpenAI 兼容 API 端点
- 可配置模型、Temperature、Max Tokens 等参数
- DeepSeek 支持思维链（Thinking）模式

## 🚀 开始使用

### 环境要求

- Flutter SDK `^3.11.5`

### 运行步骤

```bash
flutter pub get
flutter run
```

## 🛠️ 技术栈

- **Flutter / Dart**：跨平台 UI 框架
- **SQLite（sqflite）**：本地业务数据与内置词典数据库
- **flutter_tts / flutter_edge_tts**：语音合成（系统 TTS + Edge TTS）
- **audioplayers**：音频播放
- **dio**：AI 批改服务及在线资源库的网络请求
- **shared_preferences**：本地偏好设置
- **flutter_secure_storage**：安全存储 AI API Key
- **archive**：备份数据的 ZIP 压缩与解压
- **file_selector**：文件选择（备份导入）
- **share_plus**：文件分享（备份导出）
- **url_launcher**：外部链接跳转
- **package_info_plus**：应用版本信息
- **uuid**：唯一标识生成
